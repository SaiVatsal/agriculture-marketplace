# TerraAgri — Farmer-to-Buyer Agricultural Commodity Exchange

An earthy olive-and-wheat styled agricultural marketplace, wholesale spot-price index, and meteorological agronomic advisory platform built with React 18, Vite 5, Tailwind CSS, and Zustand.

## Features
- **Field-Direct Crop Lots**: Wholesale marketplace for organic durum wheat, heirloom plum tomatoes, cold-extracted olive oils, and citrus fruits.
- **National Commodity Spot Index**: Real-time daily price tracking with 7-day ranges and percentage delta indicators.
- **Micro-Climate Weather Advisory**: Real-time agronomic guidance incorporating soil moisture, pest vulnerability indexes, and harvest timing.
- **Commercial Freight Ordering**: In-app procurement contracts with automatic total calculations and freight dispatch status tracking.
- **Farmer Listing Studio**: Farm producers can list crop lots with pricing, minimum order quantities, moisture content metrics, and harvest dates.

## Running Locally
```bash
npm install
npm run dev
```
Port: `http://localhost:3045`
